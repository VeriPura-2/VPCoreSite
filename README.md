# VeriPura Core site

Static site for VeriPura Core and its industry solutions, served with GitHub Pages.

- index.html: landing page (industry solutions built on Core)
- core.html: VeriPura Core, the engine
- food.html (served at food.veripura.com), building-supplies.html, cosmetics.html, supplements.html, pharmaceuticals.html: industry solutions
- privacy.html: privacy notice

Contact forms post to Formspree (endpoint set in each page). Complete the placeholders in privacy.html before launch.
